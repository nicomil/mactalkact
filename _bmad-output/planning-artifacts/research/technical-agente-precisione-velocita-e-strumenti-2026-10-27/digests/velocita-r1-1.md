## Leads

- Verificare se Claude Code `-p` con `--bare` + `--mcp-config` + `--system-prompt` produce un prefisso identico tra invocazioni (quindi cache hit cross-processo): il changelog 2.1.302 parla di "shared prompt cache" tra nuove conversazioni, ma manca un doc esplicito; misurare `cache_read_input_tokens` nel `result` di due run consecutive.
- Agent SDK TypeScript: pagina `agent-sdk/typescript` e `agent-sdk/sessions` per il V2 session API (processo CLI persistente con `--input-format stream-json`) come alternativa a un `-p` fresco per richiesta; non letta per budget.
- `platform.claude.com/docs/en/build-with-claude/fast-mode` per i dettagli API (header/param `speed`, waitlist Console) e per confermare se Sonnet 5.5 resterà esclusa.
- Pagina Claude Code `mcp.md#server-status-detail` sulla "MCP discovery cache" (condizioni in cui la tool list cachata evita l'attesa).
- `codex exec --json` e `codex app-server` su learn.chatgpt.com/docs/non-interactive-mode: versione CLI corrente (0.16x non verificata) e opzioni di telemetria (`metrics_exporter`).
- Artificial Analysis pagine Sonnet 5.5 / Opus 5.5 per TTFT a effort low su input ~10k (confronto con Haiku 5.5 low 9,56 s).
- Apple WWDC 2026 / macOS 27 release notes FoundationModels per eventuali novità su unload del modello e latenza strutturata.

## Cercato e non trovato

- Numero ufficiale Anthropic di latenza di avvio di `claude -p` (con o senza `--bare`): il doc dice solo "reduce startup time".
- Conferma esplicita nei doc che due invocazioni `-p` separate condividano la prompt cache (solo inferenza dall'isolamento per workspace + changelog 2.1.302).
- Fast mode per Sonnet 5.5 o Haiku 5.5: escluso esplicitamente dal doc.
- Benchmark di affidabilità tool-use Haiku 5.5 vs Sonnet 5.5 (tau-bench, MCP Atlas): The Batch non li riporta; Terminal-Bench 4.0 solo in un grafico senza numeri.
- TTFT ufficiale Anthropic per Sonnet 5.5 / Opus 5.5 / Haiku 5.5 a effort low con tool: nessuna cifra ufficiale; solo Artificial Analysis con ragionamento incluso.
- Overhead ufficiale di avvio di `codex exec` e versione Codex CLI 0.16x: solo dati aneddotici (900 ms telemetria, ~6 s TUI).
- Confronto misurato Streamable HTTP vs stdio per latenza per chiamata MCP: i doc trattano solo i tempi di connessione al primo turno.
- Apple: tempo di unload del modello FoundationModels dopo idle, latenze misurate per `@Generable` su M1, novità ottobre 2026 / macOS 27.
- Primitive computer-use specifiche di Claude Code 2.1.x (solo toolset API `computer_toolset_20260801`).
